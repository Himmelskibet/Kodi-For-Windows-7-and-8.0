# Kodi-For-Windows-7-and-8.0
Latest versions of XBMC's Kodi patched to work on Windows 7 and 8.0

The latest version of Kodi that officially supports Windows 7 and 8.0 is Kodi 20.5 (Nexus).
This repository will consist of newer versions of Kodi patched to work on these OSes. It will also be pre-extracted, as the original installer artifically blocks anything prior to 8.1.

# Prerequisites for these newer versions of Kodi to work on these OSes:
Windows 7/Server 2008 R2: KB2670838, Visual C++ (download the July 2025 package from https://www.techpowerup.com/download/visual-c-redistributable-runtime-package-all-in-one/ and install these), .NET Framework 4.8, KB4474419 and KB4490628 also recommended

Windows 8.0/Server 2012: the Visual C++ July 2025 package mentioned above, .NET Framework 4.8 (Windows 8.0 Core/Pro/Enterprise will need the patch from https://legacywindowssoftware.duckdns.org/files/Patch%20to%20install%20.NET%20Framework%204.8%20and%20Internet%20Explorer%2011%20on%20Windows%208.0/ to install .NET Framework 4.8, read the "How to install" text)
